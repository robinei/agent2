Exemplars were load-bearing for two things that 27.1 took away: showing
how a program *ends*, and showing how much belongs in one. Completing a
program now continues by itself and `done()` is the only stop, so both
lessons are stated as rules rather than demonstrated — and the
demonstration was never free. Every exemplar we ship is careful,
commented and considered, which is the register the model then writes
in: 14.7KB of reasoning per run against pi's 3.5KB on the identical
model at the identical `reasoning_effort: high`.

This variant asks what the examples are still buying.
